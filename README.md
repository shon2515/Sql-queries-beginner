# 📊 Sales Data Analysis Project (SQL, Excel, Tableau)

## 📌 Project Overview
This is a beginner-friendly data analytics project focused on analyzing sales data using SQL, Excel, and Tableau. The project demonstrates the full data analysis process from data cleaning to visualization.

---

## 🎯 Objectives
- Clean and preprocess raw sales data
- Perform data analysis using SQL queries
- Analyze trends and patterns in Excel
- Build interactive dashboards in Tableau

---

## 🛠 Tools & Technologies
- SQL
- Microsoft Excel
- Tableau
